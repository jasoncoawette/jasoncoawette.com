# Clovis

Personal Finance · iOS  
2025 — Present

## Context

Clovis is a personal finance app built for people who want to build their own personal finance OS. The product centers on rules, structure, and control over how money moves.

## Problem

Most finance apps show a snapshot of accounts but don't move money. Users can see balances, but they can't set up systems that act on their behalf in one place.

## Role

Founder and Software Engineer.

Currently developing the product across iOS, macOS, and web. I design the interface, define the system structure, and implement automation logic.

I develop SwiftUI front ends, web interfaces, and a centralized Rust backend that supports speed, reliability, and clear system state.

I write product copy that explains system behavior and guides user action.

## Outcome

Clovis allows users to automate money movement through clear rules and visible state. This reduces manual effort while keeping behavior easy to understand.

## Learning

Sticky products give users control without exposing complexity.  
Less is more.

## StudyGenie

Education · Web  
2024

### Context

StudyGenie is an AI study tool built as a competitor to Quizlet. The product helps students learn by generating quiz questions and answers.

Currently, the system supports over 60,000 active users.

### Problem

Many study tools don't help students retain knowledge. Review often ignores timing, repetition, and feedback quality.

### Role

I designed and built the landing page and key front-end flows. I also contributed to quiz design and study schedules based on learning patterns.

My work focused on layout, motion, and delightful interactions.

### Outcome

The landing page drove a significant portion of user sign-ups. The front-end work supported growth without adding interface complexity.

### Learning

Good design aligns with natural instinct and behavior patterns.
